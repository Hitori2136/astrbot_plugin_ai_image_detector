# astrbot_plugin_ai_image_detector

**发送 `/AI吗` + 图片，检测图片是否带有 OpenAI 来源水印。**

插件把图片交给 OpenAI 官方的 Content Provenance API，检查其中是否包含 C2PA 内容凭证、SynthID 水印等来源信号，再把结论发回群里。

## 使用教程

### 1. 安装本插件

在 AstrBot 的插件页面装好并启用本插件。

### 2. 配置 OpenAI API Key

打开插件配置，填这一项：

| 配置项 | 值 |
| --- | --- |
| `openai_api_key` | OpenAI API Key（`sk-` 开头） |

直连 `api.openai.com` 不通时再补代理：

| 配置项 | 值 |
| --- | --- |
| `proxy` | 例如 `http://127.0.0.1:7890` |
| `use_env_proxy` | 代理留空时才生效，决定是否沿用系统代理 |

保存后即生效，没生效就到插件卡片上点「重载插件」。

### 3. 使用

图片和 `/AI吗` 放在**同一条消息**里，群聊里先 @机器人：

```text
[图片] @机器人 /AI吗
```

也可以**引用**一条图片消息，再发送：

```text
[引用图片] @机器人 /AI吗
```

指令大小写不敏感（`/ai吗`、`/Ai吗` 都可以）。私聊里不需要 @机器人。

## 检测结果

| 情况 | 回复 |
| --- | --- |
| 检测到水印 | `检测到 OpenAI 水印，图片是 AI 制作。` |
| 未检测到 | `未检测到 OpenAI 水印。` |

接口返回了模型名就用模型名，例如 `图片是 gpt-image-2 制作。`；取不到时写「AI 制作」。

### 检测明细

开启「附上检测明细」后，结论下面会多一段：

```text
检测明细：
来源：C2PA 内容凭证
状态：已检出
模型：gpt-image-2
签发方：OpenAI
校验：trusted
```

多个来源信号会各自成块，中间空一行；`模型`、`签发方`、`校验`、`生成时间` 取不到时整行省略。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `openai_api_key` | 空 | OpenAI API Key |
| `api_base` | `https://api.openai.com/v1` | 接口地址，可指向自建网关 |
| `proxy` | 空 | 代理地址，例如 `http://127.0.0.1:7890` |
| `use_env_proxy` | 是 | 代理留空时是否沿用系统代理 |
| `quote_reply` | 是 | 回复时引用触发指令的那条消息 |
| `reply_with_at` | 否 | 回复时 @ 提问者 |
| `max_images_per_message` | `1` | 单条消息最多检测几张图（1–5） |
| `timeout_seconds` | `60` | 请求超时（5–300 秒） |
| `notify_on_start` | 否 | 请求前先发一条「正在检测…」 |
| `show_details` | 否 | 结论文案下另起一段，附上检测明细 |

## 常见问题

**回复「没有识别到图片」**

图片和 `/AI吗` 不在同一条消息里，或者引用消息里没有图。

**一次发好几张图，只回复了一条**

默认只检测第一张，把 `max_images_per_message` 调大（最大 5）。

## 注意事项

- 图片会被上传到 OpenAI，不要检测涉及隐私、未公开或涉密的内容。
- **「未检测到」不等于「不是 AI 生成」**。只表示没有找到 OpenAI 支持的来源信号。元数据被平台压缩或二次保存抹掉、水印被削弱、图片来自更早的模型或非 OpenAI 的模型，都可能得到这个结果。结论仅供参考。
- 插件只处理图片，不处理音频与视频。
